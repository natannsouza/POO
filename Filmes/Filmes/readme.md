# CineClub — Sistema de Gerenciamento de Locadora

## 1. Visão Geral

O **CineClub** é um sistema de gerenciamento para locadoras de filmes. Ele permite controlar o cadastro do acervo, dos clientes e das locações realizadas.

## 2. Funcionalidades Principais

- Cadastro de filmes com código, título, diretor, ano e gênero.
- Cadastro de clientes com CPF, nome e telefone.
- Registro de locações, vinculando um filme a um cliente, com data de devolução calculada automaticamente, considerando um prazo de 3 dias.
- Devolução de filmes, com baixa automática na locação.
- Relatório de filmes atualmente locados.
- Relatório de filmes em atraso.

## 3. Observação

Não é necessário desenvolver a funcionalidade de empréstimo, pois ela não fará parte da prova. Este documento faz parte da lista de exercícios para a **N2 de POO**.
